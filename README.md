
Face & Smile Detection using OpenCV

A real-time Face and Smile Detection project built using Python and OpenCV.

Features

- Real-time face detection using webcam
- Real-time smile detection
- Face and smile highlighting using rectangles
- Uses Haar Cascade classifiers

Technologies Used

- Python
- OpenCV
- Haar Cascade Classifier

How to Run

1. Install OpenCV

pip install opencv-python

2. Run the project

python face_smile_detection.py

3. Use the webcam

Allow camera access when prompted.

Press Q to close the program.

What I Learned

Through this project, I learned the basics of Computer Vision, webcam processing, Haar Cascade classifiers, and real-time face and smile detection using OpenCV.
